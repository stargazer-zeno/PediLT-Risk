# Contributing

Contributions are welcome through GitHub issues and pull requests.

1. Never include clinical records or other sensitive data.
2. Use synthetic fixtures for tests and examples.
3. Run the backend, frontend, and research smoke tests described in the root README.
4. Document changes to data contracts, model artifacts, probability semantics, or deployment requirements.
5. Keep ML and LLM outputs independent; missing LLM probabilities must remain `null`.

By contributing, you agree that your contribution is licensed under Apache-2.0.
